# ADAM MK CHAT

**ADAM MK CHAT** is a global social networking and messaging platform where people can connect, chat, share photos, videos, music, and 24-hour status updates.

## Key Features
- **Messaging:** Private chat and group conversations.
- **Media & Music Sharing:** Share posts with text, photos, videos, and music/audio.
- **24-Hour Status & Stories:** Share updates that automatically expire after 24 hours.
- **Social & Profile:** User profiles, friends/followers, likes, comments, sharing, and notifications.
- **Safety & Privacy:** Block users, report content/users, and privacy settings.
- **Multi-Language Support:** Designed for English, Hausa, French, and Arabic.

## Platforms & Tech Stack
- **Platforms:** Web App (PWA) & Android App (APK via Capacitor)
- **Hosting & Version Control:** GitHub & GitHub Pages
- **Backend & Auth:** Firebase
- **Media Storage:** Cloudinary

## Project Structure
- `index.html` — Main application interface and client logic
- `README.md` — Project overview and documentation
- `PROJECT_BACKUP.md` — Detailed project backup, architecture, and roadmap

## Getting Started
1. Clone or open the repository (`adam-mk-chat`) on GitHub.
2. Open `index.html` in a web browser or enable **GitHub Pages** (`Settings > Pages > main branch`) to view it live.
